## 1. 한눈에 보기 - 건물 안내도

BookOasis 세션(일반·성인·오디오북·비디오)마다 한 층, 보관함마다 서가 구역, 작품마다 책장의 책(표지)입니다.
고른 보관함이 없는 세션은 층이 생기지 않으므로 층 번호는 당겨질 수 있습니다.

| 층 | 서가 | 특별 코너 | 필요한 것 |
|---|---|---|---|
| 1층 일반 | 만화·웹툰·소설 (여기서 읽기) | **입구 오른쪽** 브런치 연재 낭독 코너 · **입구 왼쪽** 오락실 · 안내 데스크·라운지·소식판 · **유리 자동문 → 바깥 앞마당·보도** | 낭독: 기본 켜짐 / 오락실: 미니게임 모듈 |
| 2층 성인 | 성인 서재 | - | 관람자는 '성인 층 허용'이어야 보임 |
| 3층 오디오북 | 오디오북 (여기서 듣기) | **입구 오른쪽** 청음 부스 | - |
| 4층 비디오 | 영상 (여기서 보기) | **입구 오른쪽** 시청 부스 | - |
| 맨 위 영화관 | - | 상영관 (큰 스크린 + 좌석 6줄) - YMPlayer의 IPTV·텔레그램 상영 | `LIB3D_YMPLAYER_*` |

어느 층이든: 손님들(사람·스톰트루퍼·엘프·**로봇 손님**), 함께 보는 사람·채팅, AI 직원(사서·도슨트)과 AI 손님(AI 설정 시), 창밖 풍경(시간·계절·날씨), 표지 포스터, 의자에 앉기.

## 2. 설치 (필수)

### 2-1. 준비물

| 필요한 것 | 설명 |
|---|---|
| BookOasis DB 읽기 권한 | MariaDB/MySQL(`PyMySQL`, `requirements.txt`에 포함) 또는 SQLite 파일. 보관함·작품 목록을 여기서 읽습니다 |
| BookOasis 주소 | 표지(`/covers/…`)와 작품 상세·BookOasis 뷰어 링크 |
| 책 파일을 같은 경로로 | **여기서 읽기·듣기·보기**는 DB의 `books.file_path` 그대로 파일을 엽니다. BookOasis와 **같은 경로로 파일이 보여야** 합니다(같은 서버·같은 마운트, 도커면 같은 경로로 볼륨). 안 되면 [BookOasis 뷰어로 읽기]만 됩니다 |
| 브라우저 | WebGL이 되는 최신 크롬·엣지·사파리·파이어폭스. three.js와 사람·가구 모형은 인터넷(cdnjs·jsdelivr)에서 받습니다 |

### 2-2. `.env` 최소 설정

```env
LIB3D_ENABLED=true

# BookOasis DB - {db_type}은 세션 이름(general, adult …)으로 바뀐다
BOOKOASIS_DB_URL=mysql://bookoasis:비밀번호@192.168.0.31:3306/bookoasis_{db_type}
#   SQLite면: BOOKOASIS_DB_URL=sqlite:////BookOasis경로/db/{db_type}.db
#   세션마다 DB가 다르면: BOOKOASIS_DB_URL_GENERAL= / _ADULT= / _AUDIOBOOK= / _VIDEO=
BOOKOASIS_DB_TYPES=general,adult,audiobook,video

# BookOasis 주소 (이 서버에서 열리는 주소)
BOOKOASIS_URL=http://127.0.0.1:5930
# 위 주소가 서버 안에서만 통하면, 브라우저가 여는 주소를 따로
LIB3D_PUBLIC_URL=http://192.168.0.10:5930
```

### 2-3. 적용 · 업데이트

```bash
cd /opt/bookoasis_assistant && git pull && systemctl restart bookoasis_assistant
# 도커: cd /opt/bookoasis_assistant && git pull && docker compose up -d --build
```

> 서비스가 어떤 파이썬으로 도는지는 `systemctl cat bookoasis_assistant | grep ExecStart`로 봅니다.
> 패키지를 더 설치할 때(예: `edge-tts`) **그 파이썬(venv)** 에 넣어야 합니다 - [3-3](#3-3-브런치-낭독-edge-음성-선택) 참고.

### 2-4. 확인

1. 사이드바에 **BookOasis 3D 서재**와 그 아래 **둘러보기 · 설정 · 인물 수 · 창밖 풍경 · 3D 모형 · AI 직원 · AI 설정**이 보인다.
2. [둘러보기]에서 1층 로비가 뜨고, 서가에 표지가 붙는다(가까운 책부터 받아 옴).
3. 책을 눌러 [여기서 읽기]가 열린다. 안 열리면 [10. 문제 해결](#10-문제-해결)의 경로 항목.
4. [설정]에서 보여 줄 보관함을 고른다(고른 것이 없는 세션은 층이 사라짐).

### 3-1. AI 연결

[3D 서재 > AI 설정]에서 넣고 저장하면 `.env`에 들어갑니다(파일 권한 0600).

| 항목 | `.env` 키 | 설명 |
|---|---|---|
| 연결 방식 | `LIB3D_AI_PROVIDER` | `openai`(기본) = OpenAI 호환 `/chat/completions` (LiteLLM·Ollama·LM Studio·OpenAI, 추가 패키지 없음) / `anthropic` = Claude API (`pip install anthropic`) |
| API 주소 | `LIB3D_AI_BASE_URL` | OpenAI 호환일 때. 예 `http://192.168.0.10:4000/v1` |
| API 키 | `LIB3D_AI_API_KEY` | anthropic에서 비우면 `ANTHROPIC_API_KEY` |
| 모델 | `LIB3D_AI_MODEL` | 게이트웨이에 등록된 이름 그대로 (예 `my-model`). anthropic은 비우면 `claude-opus-5-5` |
| 하루 호출 한도 | `LIB3D_AI_DAILY` (1000) | 손님 대화·직원 응대·자율 업무를 합친 하루(자정 기준) 호출 수. 0이면 없음. [AI 설정]에 오늘 쓴 횟수 |
| 손님 대화 | `LIB3D_AI_CHAT`, `LIB3D_AI_CHAT_SEC` (60) | 두 손님이 무작위 책 한 권을 두고 나누는 말풍선. 가까이 있고 탭이 보일 때만 부름 |
| AI 직원 응대 | `LIB3D_AI_ASK` | 채팅의 `@사서`·`@도슨트`에 답하기 (모델이 도구 호출을 지원해야 함) |

**AI가 쓰는 도구** - 세 갈래입니다.

| 도구 | 설정 | 내용 |
|---|---|---|
| BookOasis MCP | `LIB3D_MCP_COMMAND` | 서재 데이터 (읽기 전용 도구만 붙임) |
| 기본 도구 | `LIB3D_AI_BUILTIN` (켜짐) | `now` 날짜·시각, `weather` 날씨(Open-Meteo, 키 없음), `fetch_url` 공개 웹 페이지 읽기(내부 주소는 막음) |
| 추가 MCP | `LIB3D_MCP_SERVERS` | 한 줄에 `이름 = 실행 명령` 또는 `이름 = https://주소`. **모든 도구(쓰기 포함)를 그대로** 쓰므로 믿을 수 있는 서버만 |

```text
# BookOasis MCP 실행 명령 (LIB3D_MCP_COMMAND)
python3 /BookOasis경로/tools/mcp_server.py              # 같은 서버에 직접 설치
docker exec -i bookoasis python3 tools/mcp_server.py    # 도커 컨테이너(bookoasis)

# 추가 MCP 예 ([AI 설정]의 '추가 MCP 서버' 칸)
fetch = uvx mcp-server-fetch
time = uvx mcp-server-time --local-timezone=Asia/Seoul
search = https://내-검색-mcp-주소/mcp
```

- 실행 명령은 이 프로그램이 도는 곳(도커면 컨테이너 안)에서 실행됩니다. `uvx`·`npx`·`docker`가 거기 있어야 합니다.
- **[MCP 연결 시험]** 으로 서버마다 ✓(도구 수) / ✗(이유)를 확인하세요. 하나가 실패해도 나머지로 답합니다.
- LLM 서버가 붐비면(503)·한도면(429) 두 번 더 시도합니다. 계속 실패하면 LLM 쪽 사정이니 잠시 뒤 다시 하거나 LiteLLM에 대체 모델을 설정하세요.

### 3-2. AI 직원 · AI 손님

AI 연결을 마치면 자동으로 나옵니다. 끄고 켜기·성격·업무는 [3D 서재 > AI 직원]에서 정합니다(자세한 쓰는 법은 [6-6](#6-6-ai-직원과-ai-손님)).

- **자율 업무**: 서버가 30초마다 살펴 때가 된 업무를 하나씩 합니다(직원: 추천 도서·서재 점검·구역 순찰·대표에게 보고, 길 건너 사람들: 브리핑·서재 나들이, 손님: 방문).
- **서재에 아무도 없으면 모두 쉽니다**: 들어와 있는 사람이 없으면(모두 [나가기]·로그아웃·창 닫기, 또는 창을 숨긴 지 8초) 직원 업무·손님 방문을 하지 않아 AI 호출도 없습니다. 누가 들어오면 밀린 업무를 하나씩 다시 합니다.
- 오늘 호출을 한도의 **70% 넘게** 썼으면 AI 손님은 오지 않습니다(사용자 몫을 남김). 한도를 다 쓰면 직원 업무도 다음 날로 미룹니다.
- 기본 주기면 직원 약 150회 + 손님 방문 약 20번(번마다 10~15회)으로 하루 400~500회 안팎을 씁니다.

### 3-3. 브런치 낭독 (Edge 음성, 선택)

코너 자체는 기본으로 켜져 있고(`LIB3D_BRUNCH=true`), 서버에서 `api.brunch.co.kr`·`brunch.co.kr`에 접속할 수 있으면 됩니다.
목소리는 기본이 **브라우저 음성**(기기의 한국어 음성 1~2개)이고, 서버에 `edge-tts`를 넣으면 **Edge 음성 14개**(선히·인준·현수 + 다국어)가 생깁니다.

```bash
systemctl cat bookoasis_assistant | grep ExecStart        # 서비스가 쓰는 파이썬 확인

# A) …/venv/bin/python 이면 그 venv에
/opt/bookoasis_assistant/venv/bin/pip install edge-tts
systemctl restart bookoasis_assistant

# B) /usr/bin/python3 (시스템 파이썬)이면 - 우분투 24.04·데비안 12는 pip가 막힘(externally-managed-environment)
#   권장: venv를 만들고 서비스를 그쪽으로
cd /opt/bookoasis_assistant
apt install -y python3-venv                                 # venv가 없다는 오류가 나면
python3 -m venv venv && venv/bin/pip install -r requirements.txt edge-tts
systemctl edit --full bookoasis_assistant                   # ExecStart=/opt/bookoasis_assistant/venv/bin/python /opt/bookoasis_assistant/app.py
systemctl daemon-reload && systemctl restart bookoasis_assistant
#   간단히: pip install --break-system-packages edge-tts && systemctl restart bookoasis_assistant
```

- 확인: 낭독 패널 목소리 목록에 **"Edge 음성 (서버)"** 묶음이 보이면 성공. "서버에 edge-tts가 없습니다"면 다른 파이썬에 설치된 것.
- Edge 음성은 마이크로소프트 Edge '소리 내어 읽기'의 무료 비공식 경로입니다(키·요금 없음, 서버에서 `speech.platform.bing.com` 접속 필요).

### 3-4. 영화관 (YMPlayer)

서재 서버가 YMPlayer에 **서버끼리 로그인**해 IPTV·텔레그램을 대신 받아 넘기고, 상영관 **스크린에 직접** 띄웁니다.
브라우저는 서재 주소만 쓰므로 https/http 섞임이나 로그인 쿠키 문제가 없습니다.

```env
LIB3D_YMPLAYER_URL=http://192.168.0.10:8899        # 브라우저에서 열리는 YMPlayer 주소 ([YMPlayer 새 탭] 버튼, 영화관 층을 만듦)
LIB3D_YMPLAYER_INTERNAL=http://127.0.0.1:8899      # 이 서버가 부를 주소 (같은 서버면 127.0.0.1, 비우면 위와 같음)
LIB3D_YMPLAYER_USER=library                        # 서재용 YMPlayer 계정
LIB3D_YMPLAYER_PASSWORD=비밀번호
LIB3D_YMPLAYER_VIEWERS=true                        # 관람자 계정도 영화관을 볼지
```

1. YMPlayer [설정 > 사용자]에서 서재용 계정을 **일반 사용자**로 만들고, [볼 수 있는 범위]로 보여 줄 IPTV·텔레그램 채널만 고릅니다.
2. 위 값을 넣고 재시작 → 맨 위에 **영화관** 층이 생깁니다.
3. 서재에는 소스 이름·채널만 넘기고 M3U 주소·API 키는 넘기지 않습니다. 중계하는 것은 IPTV 채널·편성표·스트림, 텔레그램 채널·영상·썸네일·스트림·변환뿐이고 나머지 YMPlayer 기능은 막습니다.

> 계정(`USER`/`PASSWORD`)을 넣지 않으면 예전 방식으로 YMPlayer 화면 자체를 띄웁니다: 같은 사이트·같은 방식(http/https)이면 서재 위 창으로, 아니면 새 탭으로(`LIB3D_YMPLAYER_EMBED` = `auto`(기본) / `tab` / `frame`).

## 4. 계정과 권한

사이드바 아래 [설정 > 사용자]에서 추가하고 권한을 고릅니다. 관리자는 한 명 이상 남아야 합니다.

| 할 수 있는 것 | 관리자 | 관람자 | 관람자 (성인 층 허용) |
|---|:-:|:-:|:-:|
| 다른 화면 (웹툰 다운로더·드라이브 감시·미니게임 메뉴·사용자 관리) | ✓ | - | - |
| 3D 서재 설정 메뉴 (보관함·인물 수·창밖 풍경·3D 모형·AI·AI 직원) | ✓ | - | - |
| 둘러보기·읽기·듣기·보기, 앉기, 도서관 밖, 함께 보기·채팅 | ✓ | ✓ | ✓ |
| 2층 성인 서재 (층·표지·책 열기) | ✓ | - | ✓ |
| AI 직원 부르기 (`@사서` 등) | ✓ 모든 도구 | ✓ 서재 검색·무작위 책·시각·날씨만 | ✓ (성인 서재 포함) |
| 브런치 낭독 · 청음/시청 부스 · 오락실 | ✓ | ✓ | ✓ |
| 영화관 | ✓ | `LIB3D_YMPLAYER_VIEWERS`에 따라 | 같음 |

## 6. 코너별 안내

### 6-1. 브런치 연재 낭독 코너 (1층 입구 오른쪽)

간판·낭독대·**엘프 낭독가**·듣는 의자 두 개·안내 화면. 브런치 요일별 브런치북 연재를 골라 소리 내어 읽어 줍니다([ym_brunch](https://github.com/yume-script/ym_brunch)와 같은 방식).

- **안내 화면**: 오늘 요일 새 회차 수와 제목(NEW), 10분마다 갱신. 낭독 중이면 "지금 낭독 중".
- **안내 화면·낭독대를 누르거나 의자에 앉으면** 패널: 요일 탭(월~일·완결, 탭마다 새 글 수) → 최신순 목록([더 보기]) → 본문(이전 화/다음 화, 브런치 원문 ↗).
- **낭독**: ▶ / ❚❚ / ■, 읽는 문단 강조·따라가기, 문단을 누르면 거기서부터, 속도 0.8~2.0x, 목소리, **다음 화 이어서**. 읽는 문장은 낭독가 말풍선에도 뜨고, 패널을 닫아도 계속 들으며 걸을 수 있습니다.
- 소리는 고른 사람에게만. 멤버십(유료) 글은 앞부분만 나옵니다.

### 6-2. 청음 부스 · 시청 부스 (3층·4층)

입구 오른쪽에 헤드폰이 걸린 의자 4개(시청 부스는 의자 앞 작은 화면). **앉으면** 그 층 작품 고르기 창(보관함 탭·제목 찾기)이 열리고, 고르면 재생합니다. 서가에서 책을 눌러 [여기서 듣기/보기]도 같습니다.

- 재생 화면: 표지 또는 영상, 트랙 목록, ⏮ · -15초 · +30초 · ⏭, 속도 0.8~2x, 다음 트랙 자동. Space 재생·일시정지, ←→ 트랙.
- **이어 듣기**: 트랙·위치를 5초마다 기억합니다.
- **들으며 걷기**: 오디오북은 [서재로]를 눌러도 계속되고 위쪽에 작은 막대(🎧 제목·시간·▶/❚❚·열기·✕)가 뜹니다. 영상은 닫으면 멈춥니다.
- 장마다 파일이 나뉜 폴더(두 단계 안쪽까지)도 트랙 목록으로 묶습니다. 파일은 조각(Range)으로 보내 바로 건너뛸 수 있습니다.
- 브라우저가 못 여는 형식(mkv 안 HEVC·AC-3, avi 등)은 재생되지 않을 수 있습니다 → BookOasis 뷰어나 영화관(YMPlayer).

### 6-3. 영화관 (맨 위 층)

로비 안쪽 상영관: 커튼·큰 스크린·빨간 좌석 6줄·가운데 통로. **스크린을 누르거나 좌석에 앉으면** 고르기 창이 열립니다.

- 📺 **IPTV**: 그룹·찾기, 편성표가 있으면 '지금: 방송 제목'. ✈ **텔레그램**: 채널·찾기·더 보기.
- 고르면 **스크린에 상영**(가로는 영상 비율에 맞춤). 위쪽 막대: ❚❚/▶ · -10초/+30초(텔레그램) · 소리 · [크게 보기](화면 가득 ↔ 스크린) · [고르기] · ■.
- 재생 엔진은 YMPlayer와 같습니다: HLS(hls.js, 사파리는 기본), MPEG-TS 생방송(mpegts.js), 텔레그램은 원본 또는 YMPlayer 서버 변환(사파리는 HLS 변환). DASH(.mpd)는 아직 안 됩니다 → [YMPlayer 새 탭].
- 소리와 스크린 영상은 고른 사람에게만 보입니다. 다른 층으로 가면 멈춥니다.

### 6-4. 오락실 (1층 입구 왼쪽)

미니게임마다 오락기 한 대(8대까지): 색 몸통·조이스틱·버튼·게임 이름 화면, 앞에 의자, 천장에 "오락실 · 미니게임" 간판.

- **오락기를 누르거나 의자에 앉으면** 그 게임이 화면 가득 열립니다(미니게임 메뉴와 같은 게임). 위쪽 목록으로 다른 게임(8대에 못 든 것 포함).
- [오락실로] 또는 **Esc**(게임 중에도)로 닫으면 게임이 끝납니다. 창이 열린 동안 방향키는 게임에만 갑니다.
- 건물 폭이 좁으면(보관함이 적을 때) 오락실을 만들지 않습니다.

### 6-5. 로봇 손님

three.js 예제(webgl_animation_skinning_morph)의 노란 로봇이 층마다 한 대(기본, [인물 수]에서 0~20) 통로를 걸어 다닙니다.
- 걷다가 자주 멈춰 **손 흔들기·고개 끄덕·엄지척·춤·점프·고개 젓기** 중 하나를 합니다.
- 가까이(약 3m) 가면 이쪽을 돌아보며 손을 흔들거나 엄지를 들고, 잠깐 **놀란 표정**(얼굴 모핑)을 짓습니다(같은 로봇은 25초에 한 번).
- 모형은 jsdelivr에서 처음 한 번 받습니다(받기 전에는 나오지 않음).

### 6-7. 재즈 청음실

길 건너 청음실 건물([창밖 풍경 > 거리]의 '재즈 청음실 건물', 기본 RECORDS) 1층. 큰 스피커 둘, 앰프(VU 미터)와 턴테이블, LP 선반, 네온 'JAZZ', 안락의자 셋, 벽 화면(지금 곡·앨범 커버·스펙트럼 막대).

- 소리는 **고른 사람의 기기에서만** 나고, **청음실을 나가면 멀어질수록 작아집니다**(아이폰·아이패드는 브라우저가 소리 크기 조절을 막아 기기 볼륨으로 듣고, 멀리 가면 꺼짐). 패널을 닫아도 계속 들리며, 다른 층으로 가거나 [나가기]면 멈춥니다.

- 방송국 목록은 [colaiuta77/jazzradio](https://github.com/colaiuta77/jazzradio)를 참고했습니다(코드는 이 프로그램에 맞게 새로 작성).

| 배준 · 청음실 주인 (하늘색) | 길 건너 재즈 청음실 | `@DJ` `@디제이` | 6시간마다 서재 나들이 |

- 직원 행동: 걸어서 이동, 소리 내어 말하기(말풍선 + 같은 층 채팅), 찾은 책 앞에서 노란 화살표로 가리키기, 로비 **소식판** 바꾸기, 기억하기. 여기에 AI 설정의 도구를 함께 씁니다.
- **소식판**(로비): 직원이 건 내용 + 최근 활동 5개. 사용자와의 문답 내용은 "이용자 응대"로만 표시됩니다.
- 손님과 직원의 대화는 그 층 채팅에 모두에게 공개됩니다. 손님은 성인 서재를 보지 않고, 방문 중에만(일반 층) 보입니다.
- 기억: 직원 메모, 사용자별 최근 문답 6개·취향.
- AI 직원이 나오면 원래 안내 데스크의 사서 모형은 빠집니다.
- **대표와 보고**: 사서·도슨트의 상사는 대표입니다. 사서는 하루 1번 [대표에게 보고] 업무로 서재 소식을 보고하고(`report` 행동), 보고는 대표의 메모에 쌓여 대표가 대답할 때 참고합니다. 대표 이름·성격은 [AI 직원]에서 바꿉니다(예: 디스코드 봇 캐릭터 이름으로).
- **길 건너 사람들**(대표·큐레이터·청음실 주인)은 자기 건물이 있는 1층에서만 보이고, 2층부터는 나들이로 서재에 들어왔을 때만 보입니다. [창밖 풍경 > 거리]에서 그 건물을 비우면(이름 없음) 서재 안에 있을 때만 나옵니다.
- 이미 쓰던 설정에는 업데이트 후 처음 열 때 세 사람과 보고 업무가 한 번만 추가됩니다(지우면 다시 생기지 않음).

## 8. `.env` 전체 목록

| 키 | 기본 | 설명 |

## 10. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| "BookOasis 3D 서재가 꺼져 있습니다" | `LIB3D_ENABLED=true` 후 재시작 |
| "BookOasis 보관함을 읽지 못했습니다" | `BOOKOASIS_DB_URL`·`BOOKOASIS_DB_TYPES`, DB 계정 권한, 이 서버에서 DB 접속 |
| 표지가 색 상자·제목 표지로만 | `BOOKOASIS_URL`이 이 서버에서 열리는지(`/covers/…`), BookOasis에 표지가 있는지 |
| 작품 상세·BookOasis 뷰어가 안 열림 | 브라우저에서 열리는 주소를 `LIB3D_PUBLIC_URL`에 |
| 여기서 읽기·듣기에서 아무것도 안 나옴 | 화면에 이유가 적힘. 대개 `books.file_path`를 이 서버에서 같은 경로로 볼 수 없음(마운트) |
| 영상이 안 나옴 | 브라우저가 못 여는 형식(mkv의 HEVC·AC-3, avi) - BookOasis 뷰어나 영화관으로 |
| 책장 몇 칸에만 진짜 책이 있음 | `.env`에 `LIB3D_PER_LIBRARY=120`처럼 작은 값이 남아 있지 않은지 |
| "3D 라이브러리(three.js)를 불러오지 못했습니다" | 브라우저가 cdnjs.cloudflare.com·cdn.jsdelivr.net에 접속 가능한지 |
| 사람이 공·원통 모양 / 엘프 낭독가가 사람 모형 | 모형(jsdelivr)을 받는 중이거나 못 받음 (받으면 바뀜) |
| 화면이 버벅임 | [3D 모형]을 '지금 그대로'로, [인물 수] 줄이기, `LIB3D_PER_LIBRARY` 줄이기, 하드웨어 가속 |
| 아이패드에서 버튼끼리 겹침 | 새로고침(최신 화면), 그래도면 화면을 찍어 알려 주세요 |
| AI: "API 키가 맞지 않습니다" / "연결하지 못했습니다" | 주소 끝이 `/v1`까지인지, 키, 게이트웨이의 모델 이름 |
| AI 직원이 안 보임 | AI 연결 설정, [AI 직원]에서 켜져 있는지 |
| AI가 도구를 안 씀 | 모델이 도구 호출(function calling)을 지원하는지, [MCP 연결 시험] |
| "오늘 AI 호출 한도를 다 썼습니다" | `LIB3D_AI_DAILY`를 늘리거나 다음 날까지 |
| 낭독 목록이 "브런치에서 가져오지 못했습니다" | 서버에서 `https://api.brunch.co.kr` 접속, 브런치 쪽 변경 |
| 낭독 버튼이 안 눌림 / 목소리가 없음 | 기기에 한국어 음성이 있는지, 또는 서버에 `edge-tts`([3-3](#3-3-브런치-낭독-edge-음성-선택)) |
| `pip install`이 externally-managed-environment | [3-3](#3-3-브런치-낭독-edge-음성-선택)의 B (venv) |
| 영화관 층이 없음 | `LIB3D_YMPLAYER_URL` 또는 계정이 들어 있는지, 재시작했는지 |
| 영화관 "YMPlayer 로그인 실패" / "연결하지 못했습니다" | `LIB3D_YMPLAYER_INTERNAL`(이 서버에서 열리는 주소)·계정·비밀번호, YMPlayer가 켜져 있는지 |
| 영화관에서 채널이 안 나옴 | YMPlayer에서는 나오는지, DASH(.mpd)는 아직 안 됨, [YMPlayer 새 탭]으로 비교 |
| 오락실이 없음 | `MINI_ENABLED`, 건물 폭(보관함이 아주 적으면 생략) |
